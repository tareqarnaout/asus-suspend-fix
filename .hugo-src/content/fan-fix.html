+++ title = 'ASUS Vivobook Pro 15 — Linux Battery Fan & Performance Mode Fix' description = 'Linux battery fan and performance profile troubleshooting for the ASUS Vivobook Pro 15.' +++

Field notes for the battery fan and performance profile issue. Package dependencies and asusctl commands can vary by release. The causes below describe the reported setup.

Issue Summary

When running Linux on battery power on the ASUS Vivobook Pro 15, the fans fail to spin up under heavy workloads even when the desktop power profile is set to Performance.

Reported causes

  1. WMI / EC Handshake Issue: Generic Linux power tools (power-profiles-daemon / TLP) do not always sync properly with the proprietary ASUS WMI/Embedded Controller (EC) interfaces when unplugged.
  2. asusd Default Battery Fallback: By default, asusctl sets the battery profile to Quiet, which forces the system into a low-power/silent state as soon as the charger is unplugged.
  3. powerprofilesctl Mapping Conflict: Running powerprofilesctl set performance while asusd is active triggers an inverted mapping bug that resets /sys/firmware/acpi/platform_profile to quiet.

Step 1: Install Build Dependencies & gettext (Ubuntu / Zorin OS)

Install the required compiler packages, development headers, and gettext (which provides msgfmt needed to compile translations for rog-control-center):

sudo apt update
sudo apt install make cargo gcc pkg-config openssl libasound2-dev cmake build-essential python3 libfreetype6-dev libexpat1-dev libxcb-composite0-dev libssl-dev libx11-dev libfontconfig1-dev curl libclang-dev libudev-dev checkinstall libseat-dev libinput-dev libxkbcommon-dev libgbm-dev git gettext

(Optional) Ensure you have an up-to-date Rust toolchain via rustup:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"

Step 2: Clone, Build, and Install asusctl

Clone the official repository, compile the binaries, and initialize the asusd service:

git clone https://github.com/OpenGamingCollective/asusctl.git
cd asusctl
make
sudo make install

Create the configuration directory and restart the daemon:

sudo mkdir -p /etc/asusd
sudo systemctl daemon-reload
sudo systemctl restart asusd

Step 3: Keep power-profiles-daemon Active (Do Not Mask)

Do not mask power-profiles-daemon, as masking it removes the Power Mode slider from the GNOME / Zorin Quick Settings menu. If it was previously masked, restore it:

sudo systemctl unmask power-profiles-daemon
sudo systemctl enable --now power-profiles-daemon

Step 4: Lock AC, Battery, and Active Profiles to Performance

Set asusctl so that both AC and Battery states default to Performance, and set the currently active profile via asusctl (avoid using powerprofilesctl set performance so it does not reset to Quiet):

# Set default AC and Battery profiles to Performance
asusctl profile set Performance --battery
asusctl profile set Performance --ac

# Set the active profile to Performance
asusctl profile set Performance

Step 5: Verify Kernel & Profile Status

  1. Check asusctl state:

    asusctl profile get

    Expected output:

    Active profile: Performance

AC profile Performance
Battery profile Performance

  2. Verify the kernel ACPI platform profile:

    cat /sys/firmware/acpi/platform_profile

    Expected output:

    performance

  3. Monitor temperatures and fan RPM under load:

    watch -n 1 sensors

Bonus: Fix rog-control-center Crash on X11 Sessions

If launching rog-control-center fails with neither WAYLAND_DISPLAY nor WAYLAND_SOCKET is set, either switch to a Wayland session at login or recompile rog-control-center with X11 enabled:

cd ~/asusctl
cargo build --release --features "rog-control-center/x11"
sudo make install
