LINUX TROUBLESHOOTING / SUSPEND

Fixing instant wake on an ASUS Vivobook Pro 15

Tested on the N6506CU with Zorin OS 18.1, Linux 7.0.0-42-generic, and firmware N6506CU.309.

DiagnosisTemporary testPermanent workaroundUndoBattery fan fix

What worked
Masking ACPI event 0x6F let the laptop stay in s2idle for 41 seconds and resume normally.

How we isolated the wake signal

  1. The journal showed repeated s2idle attempts ending almost immediately. /sys/power/pm_wakeup_irq reported IRQ 9, the shared ACPI interrupt.
  2. Unplugging the external keyboard and mouse receiver and disabling embedded-controller wake did not stop the immediate wake. The SD card reader logged a resume error on one attempt, but unloading its driver did not fix the wakeups.
  3. deep suspend left the machine unresponsive to the power button and required a forced shutdown. We returned to s2idle.
  4. With /sys/power/pm_debug_messages temporarily set to 1, the kernel logged ACPI non-EC GPE wakeup. The counter at /sys/firmware/acpi/interrupts/gpe6F rose by more than 5,000 in two seconds while awake.

0x6F is the firmware's ACPI General-Purpose Event number. The mask test isolated the wake signal. The underlying reason the signal kept firing remains unknown.

Test the mask for one suspend cycle

Save your work, confirm cat /sys/power/mem_sleep shows [s2idle], and leave the lid open. Suspend, wait at least 20 seconds, then press the power button once if the machine is still asleep.

echo mask | sudo tee /sys/firmware/acpi/interrupts/gpe6F &&
systemctl suspend

Remove the temporary mask after waking. A reboot also clears it.

echo unmask | sudo tee /sys/firmware/acpi/interrupts/gpe6F

Apply the workaround at boot

On the tested GRUB setup, apply this only if the temporary test succeeds. Reboot, then test suspend again.

printf '%s\n' 'GRUB_CMDLINE_LINUX_DEFAULT="$GRUB_CMDLINE_LINUX_DEFAULT acpi_mask_gpe=0x6F"' |
  sudo tee /etc/default/grub.d/99-mask-gpe6f.cfg &&
sudo update-grub

After reboot, check that cat /proc/cmdline contains acpi_mask_gpe=0x6F and that cat /sys/firmware/acpi/interrupts/gpe6F reports masked.

Undo the boot change

sudo rm /etc/default/grub.d/99-mask-gpe6f.cfg &&
sudo update-grub

Reboot to apply the rollback.
